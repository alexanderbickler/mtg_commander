How the rating works: the hard rules set the lowest bracket the deck can be in (the rules floor). The power level can only raise it. The page looks up every card on Scryfall ↗ (opens in a new tab) and scores eight factors from 0 to 10, then combines them with the formula from CodingAce's EDH power level calculator ↗ (opens in a new tab): Mana Engine × 18% + Consistency × 18% + Win Pressure × 20% + Interaction × 14% + Resilience × 10% + Protection × 8% + Disruptive Pressure × 7% + Card Quality × 5%. The table above turns that into a bracket. How each factor is scored from the cards is this site's own estimate. Draw, removal, tutor, ramp and finisher detection reads each card's rules text, so unusual wording can be missed or miscounted. Land counts use the colors Scryfall lists for each land; fetch lands count toward the basic land types they can find. If Scryfall can't be reached, the page falls back to its built-in lists of tutors, fast mana and free interaction. The Game Changers list matches the February 2026 update (53 cards). Mass land denial, extra-turn and combo detection uses built-in lists of well-known cards, so it may miss obscure ones. Always talk it over with your playgroup before the game.
